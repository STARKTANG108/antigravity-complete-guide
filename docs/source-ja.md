## 第1章：なぜ今「Google Antigravity」が最強のAIエージェントなのか？

「コードエディタ」の記憶はもう古い――5つの入口がつながる自律OS
いきなり核心を突きますね。
「Google Antigravityって、VS Codeを改造したAIエディタでしょ？」という記憶で止まっている人、多いんじゃないでしょうか。
その認識、もう半年前のものなんです。
2026年5月のGoogle I/Oで登場した「Antigravity 2.0」から、設計思想がガラッと変わりました。
今のAntigravityは、裏側の頭脳・権限・スキル・MCP設定を共通化したまま、5つの入口すべてが連動する総合プラットフォームです。
・Antigravity App：複数の並列エージェントを司令官のように監視できるデスクトップアプリ
・Antigravity CLI（agy）：黒い画面から爆速で回せて、自動化や常駐デーモン化もできるターミナル版
・公式IDE拡張＆Antigravity IDE：VS Code、JetBrains、Xcode、Zed、Android Studioなどにそのまま統合
・Antigravity Python SDK：pip install google-antigravityで自分のプログラムに組み込める
・ACP（Agent Client Protocol）：公式バイナリ（antigravity-acp）経由で、T3 Code等の外部操作盤とも接続
さらにv2.30.0以降のAntigravity Appには、個人アカウント向けに「Knowledge Work」と「Software Engineering」のレイアウト切替が入りました。
コードを書かないライターや企画職なら、Gitやターミナルを隠して「会話・ドキュメント・成果物」だけのスッキリ画面で使えます。
サイドパネルのPDFビューアで資料の一文をなぞって「Quote」や「Comment」を押すだけで、ピンポイント修正を飛ばせるのも本当に快適なんです。
11月の神アプデ連打：/btwの昇格・内蔵ブラウザ・音声対話・マルチエージェント
2026年11月のアップデート連打も凄まじいんです。
タイムラインで一番バズっていたのが、サイドクエスチョン機能「/btw」の大型アップデート。
AIに大きな作業を任せている最中、「あの仕様ってどこだっけ？」「ちょっと別案も試したいな」と思う瞬間、ありますよね。
でもAntigravityで「/btw」を打つと、メインを1ミリも止めずに、これまでの会話文脈を引き継いだ別タブ（フォーク）が横にスッと開きます。
実際にファイル検索や読み込みをして裏取りした答えを返してくれて、元の会話履歴は一切汚れません。
しかも最新アプデで、当たり案を「Insert into main conversation」でメインに合流させたり、そのまま本命の会話へ昇格（プロモート）できるようになったんです。
料理しながら横のコンロで試作ソースを作って、美味しくできたらメインの鍋に流し込むような気持ちよさなんですよね。
さらに次の機能が、拡張プラグイン探しなしで最初から全部標準装備されています。
・内蔵ブラウザ（/browser）：Chrome不要でアプリ右側に内蔵。複数タブ並列で画面検証やスクショ撮影を行い、ログイン画面だけ人間へ一時バトンタッチも可能
・OpenSSH接続（v2.33.0+）：リモートLinuxサーバーを専用ウィンドウで開き、エージェントをサーバー上で常駐実行
・Voice Mode（Gemini Live）：マイクボタンやCLIのF6から、通話感覚で声だけで指示出し・軌道修正・承認まで完結（危険操作だけは画面クリック必須）
・4段階のマルチエージェント：裏作業の「サブエージェント」、共有ボードで検品役@verifierと組む「/swarm（無料OK！）」、難解バグの「/boost」、数日規模の大改修を監査ゲート付きで回す「/teamwork」
・自律＆定期実行：完了まで止まらない「/goal」、1問ずつ要件を詰める「/grill-me」、Python指揮の「/run-workflow」、定期実行の「/schedule」＆「Automations」
公式ブログでは、Neon×/swarmで2人用ゲームを構築し、内蔵ブラウザ上でエージェント自身が2人目のプレイヤーとして一緒に遊ぶデモまで公開されています。
ほかにも画像1枚から「10万セル・50万数式以上のスプレッドシート3D深度マップ」をスワーム生成した公式ショーケースや、静止画1枚からNeonが自律的にDepth Anything V2を落としてThree.jsで立体化した事例も飛び出しました。
前の世代のAIが「言われた部品を削るアシスタント」だとしたら、今のAntigravityは「設計から試運転、検品までチームで回す現場監督」なんですよね。

Google AI Ultraの計算枠で96GBのG4 GPUを立ち上げ、ComfyUI上でオープンソースの動画モデル「MiniMax H3（32kHzネイティブステレオ音声付き）」を動かしたところ、なんと45秒・1080p・音付きの連続ショート動画がそのまま出てきたという報告があるんです。
まず1280×704で4幕を前後フレームで繋ぎながら生成し、そのあとRealESRGANで1920×1080に超解像したときの実測データがこちらです。
・動画生成時間：4幕合計で約16分07秒（1幕目15秒が6分14秒、残り3幕は各10秒で約3分16秒〜3分21秒）
・1080pへの超解像時間：約6分（10秒あたりわずか約1分18秒）
・ユニット消費量：GPU処理だけで約3.7ユニット、途中で各幕のフレームを抜き出して確認しても約4.2ユニット（※G4の1時間あたり消費レートは環境や時間帯により変動）
ちょっと計算してみてください。
1本たった4.2ユニットということは、Ultraの月2,000ユニットなら45秒・1080p音付き動画が計算上で月470本以上。しかもProの月200ユニットでも月45本以上回せてしまう規模感なんです。
しかもこれが、Google公式の「google-colab-cli」と「comfy-mcp」を使うことで、手元のAntigravity（AIエージェント）から丸ごと自動操作できちゃいます。
1. ローカルのAntigravityに「google-colab-cli」と「comfy-mcp」を渡し、96GBのG4ランタイムを起動させる
2. 重みファイル（Comfy-Org版のMiniMax-H3約44GBとRealESRGAN_x2plus）はGoogleドライブへ置かず、データセンターの高速回線＋aria2で一時ディスクへ数分で直接ダウンロードする

## 第5章：【ちょっと真面目な話】弱点・注意点と「規約BAN」の境界線

レート制限・無料トライアルの罠・エディタ分離など知っておくべき注意点
ここで少しだけテンションを落として、真面目にお話しさせてください。
いいことばかり並べるのは不誠実なので、踏むと痛い弱点と注意点もハッキリお伝えしますね。
・レート制限の壁：Proでも5時間ごと回復＋週次上限があり、XHighのNeonやClaude Opus 5.5、/teamworkや/boostを連続で回すと上限に当たる（超過時は追加購入AIクレジットへ切替可能だが完全無制限ではない）
・無料トライアル中のモデル制限：Claude 5.5系やHydrogenは「非トライアルの有料Pro契約」が必須。NeonやOrchestratorも対象デバイス以外の通常トライアルでは制限あり。無料枠のClaude 4.6系とGPT-OSS-120bは2026年11月30日で削除予定
・エディタ分離：Antigravity 2.0のデスクトップアプリからコードエディタ本体が外れたため、一体型が好みならAntigravity IDEかVS Code／JetBrains公式拡張を使う形になる
・法人Workspaceアカウントは対象外：個人Google AIプランの特典は付かないため、ブラックフライデーは個人Googleアカウントで契約すること
・数字の注釈：Intelligence Index「61」はxhighのスコア。コンテキスト上限もAPI直結は100万トークンだが、Antigravity内は公式仕様上「最大512Kトークン」。社内テストの最低捏造率もハルシネーション完全ゼロではない
規約第6条のBAN問題：OpenClaw等とT3 Codeの明確な境界線
T3 Codeでスマホ連携したい人が必ず知っておくべきなのが「規約BAN問題」です。
Google Antigravityの追加利用規約（第6条）は、非公式ラッパーやプロキシ、自動エージェントループでの接続を禁止しています。
実際2026年にOpenClaw等の非公式ツールでOAuthトークンを横流ししたユーザーに対し、「403 PERMISSION_DENIED」やアカウント停止が多発しました（初回は異議申し立て復旧例あるも、再発は永久BAN）。
Googleフォーラム等で整理されている境界線は明確です。
・許容される構造：単一ユーザーの対話型開発向けに、ACP Registryの公式未改変バイナリ（antigravity-acp）を動かし、ネイティブ個人OAuth（oauth-personal）で標準JSON-RPC通信する形（T3 Codeはこの方式）
・アウトな構造：OAuthトークンを抜き取って外部プロキシへ流す、複数アカウントを自動ローテーションする、個人契約を無人の大規模ループに組み込む行為
ただし「T3 Code経由だとプラン上限後の追加AIクレジットが消化されない」というフォーラム報告もあり、今後規約運用が厳格化される可能性もゼロではありません。
メインのGoogleアカウントでリスクを負いたくないなら、スマホ操作はAntigravity公式の「Remote Control」か「Remote Agents」が一番安全です。
ローカル権限も無確認でPC全体を触れる「Turbo」は避け、Terminal Sandbox有効＋承認あり＋Git管理フォルダを守ってくださいね。
